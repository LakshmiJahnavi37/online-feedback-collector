# Online Feedback Collector with Admin Dashboard

## Objective
A full-stack web application that collects user feedback and displays analytics in an admin dashboard.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: SQLite
- Charts: Chart.js

## Features
- Feedback submission form
- Data storage in SQLite
- Admin dashboard with statistics
- Rating visualization using charts
- CSV export functionality

## How to Run the Project
1. Install Python 3
2. Install dependencies:
   pip install flask
3. Run the app:
   python app.py
4. Open browser:
   http://127.0.0.1:5000/

## Admin Dashboard
Access:
http://127.0.0.1:5000/admin-dashboard
